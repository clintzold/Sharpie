# Sharpie - Terminal Text Editor

## What is Sharpie?
**Sharpie** is a text editor built for the terminal in C#.

This project is an ongoing attempt to recreate the most basic functions of
popular terminal text editors such as **nano** and **vim**.

## Why?
The reason I am building this tool is two-fold:
  - to get my hands dirty with C#
  - to get my hands even **dirtier** playing with lower-level programming(experience that the average web development
  project doesn't provide)

### Specs

  - **Language:** C#
  - **Test Library:** Xunit
  - **OS Support:** Linux
